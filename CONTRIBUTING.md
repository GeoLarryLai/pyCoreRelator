# Contributing to pyCoreRelator

Thank you for considering a contribution to pyCoreRelator.
We welcome bug reports, feature ideas, documentation
improvements, and pull requests.

The project is under active development. A manuscript
describing it is in peer review.

## Reporting Bugs

If you find a bug, please create an issue on GitHub. Include as much detail as possible to help us recreate the problem:
* Use a clear and descriptive title.
* Describe the exact steps to reproduce the problem.
* Provide specific examples of the input data or log types that caused the error.
* Include the error traceback and your computing environment details (Python version, operating system).

## Suggesting Enhancements

Feature requests are welcome! If you have an idea for a new similarity metric, better image-to-log conversion, or optimized alignment rules, please submit an issue on GitHub.
* Explain how the enhancement would improve the workflow.
* Provide a conceptual example or relevant literature if proposing a new mathematical or stratigraphic method.

## Pull Requests

We actively welcome pull requests for bug fixes, code optimizations, and new features.
1. Fork the repository and create your branch from `main`.
2. If you add new behavior, include a short check or example that shows it works (a script, notebook cell, or test).
3. Update the documentation to reflect any changes to function parameters or outputs.
4. Ensure your code follows standard Python styling (PEP 8).
5. Open the pull request with a clear description of the changes and the problem they solve.
