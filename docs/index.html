Python package

pyCoreRelator

Larry Syu-Heng Lai

pyCoreRelator correlates geological cores and physical logs bed by bed. It aligns the signals with dynamic time warping while keeping superposition, age succession, and pinch-outs, then scores those alignments so a closer match can be treated as a stronger correlation. The same package cleans and gap-fills logs and turns core images into digital logs for that work.
